# Portafolio de Cristian Sosa

Sitio estático en HTML y CSS. Abre `index.html` en tu navegador. No necesita instalación ni compilación. También puedes usar Live Server en Visual Studio Code.

## Editar

- Textos, correo, LinkedIn y enlaces: `index.html`.
- Colores, tamaños y adaptación a móvil: `styles.css` (variables al inicio).
- Foto: `assets/cristian-sosa.jpeg`.
- CV descargable: `assets/Cristian-Sosa-CV.pdf`.
- Capturas de los proyectos: `assets/notes.png`, `around.png`, `lector.png` y `gastos.png`.

Las tipografías se cargan desde Google Fonts; sin conexión se utilizan fuentes del sistema. El contenido, las imágenes y los estilos se guardan localmente.

Verificados el 27 de octubre de 2026. Las capturas corresponden a las páginas públicas de las aplicaciones; Notes y Around muestran su pantalla de acceso. No se incluyen credenciales.

- Around: https://web-project-around-full-z2ul.vercel.app/. Su repositorio Full Stack es público, verificado en GitHub; el botón Code permite consultar el código.

- Lector: https://cristiansosa1992.github.io/Lector-de-texto-en-voz-alta/.
- CS-Music: en desarrollo. Se muestra una ilustración conceptual, el alcance previsto y el enlace a su repositorio. No se inventó una demo funcional. Cuando esté disponible, reemplaza el texto «Live · próximamente» por un enlace real.

Para publicar más adelante en GitHub Pages, sube `index.html`, `styles.css` y la carpeta `assets` manteniendo esta estructura. Este trabajo no publica automáticamente el sitio.
